# layouts.md

## Base grid and production decisions

**Canon:** Western left-to-right reading; 22-page single issue; odd pages right, even pages left; flat retro color with halftone-dot texture; dusty-gold natural light except the saturated dream sequence, which is not present in this script version.

**Layout:** Four equal rectangular tiers throughout, except Page 17, which is a one-panel full-page splash. Maximum four panels per page and three named characters per panel.

**Continuity correction:** Page 3 uses the canonical destination **Rishikesh**. The malformed layout blocks on Pages 2, 13, 14, 15, 20 and 21 have been repaired as single valid JSON objects. No plot, staging or lettering has otherwise been changed.
