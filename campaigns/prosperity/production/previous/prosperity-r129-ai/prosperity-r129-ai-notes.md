# notes.md

## Verdict

**Needs a rethink.** The current `script.md` is not a script of the approved `draft-final.md`: it uses a different prologue, different page count, different pagination and substantial reordered or invented material. Because the showrunner has fixed `draft-final.md` as the book and requires word-for-word, beat-for-beat conversion, execution cannot proceed until the Writer rebuilds `script.md` from that file.

## Findings by severity

### Blocker

#### 1. The script has the wrong page count and architecture

- **Location:** `script.md`, Pages 1–64; `draft-final.md`, entire document.
- **Problem:** The approved book is exactly 47 pages: four-page prologue, 12-page Chapter 1, 15-page Chapter 2 and 16-page Chapter 3. The script is 64 pages and includes Chapters 4–6 material that is not in `draft-final.md`.
- **Smallest repair direction:** Writer, discard the current pagination and script exactly `draft-final.md` into Pages 1–47 in order: draft-final prologue Pages 1–4; Chapter 1 Pages 5–16; Chapter 2 Pages 17–31; Chapter 3 Pages 32–47. Do not preserve the current 64-page layout.
- **Role:** Writer

#### 2. The prologue is not the approved prologue

- **Location:** `script.md`, Pages 1–10; `draft-final.md`, `00-prologue.md`, Pages 1–4.
- **Problem:** `draft-final.md` opens in 2070 with Older Alex, his daughter, the wall of patents, the paid-in-full statement and the pump-bracket sketch. `script.md` opens in 2099 with TJ, Nera, Voss and a lake-water theft. This removes the approved opening and introduces a separate story.
- **Smallest repair direction:** Writer, script the four approved “The Wall” pages word for word and in order. Remove the 2099 lake sequence, Nera, Voss and the alternate TJ plot.
- **Role:** Writer

#### 3. The script does not preserve the approved page order or chapter turns

- **Location:** `script.md`, Pages 11–44; `draft-final.md`, Chapters 1–3.
- **Problem:** Approved Chapter 1 begins on Page 5 with the three-city establishing page and ends on Page 16 with Mera choosing TRACK. In `script.md`, those beats occur on Pages 11–22. Approved Chapter 2 ends on Page 31 with the train/follower beat; in `script.md`, the equivalent material ends on Page 37. Approved Chapter 3 ends on Page 47 with Mera’s message; the current script reaches a different chapter endpoint on Page 44.
- **Smallest repair direction:** Writer, renumber and repartition every page from the approved draft rather than compressing or relocating scenes from the current script. Preserve each approved page’s beat, sequence and chapter ending.
- **Role:** Writer

#### 4. The script contains Chapters 4–6 material absent from the approved book

- **Location:** `script.md`, Pages 45–64; `draft-final.md`, end of Chapter 3 on Page 47.
- **Problem:** The script adds Leona, Mera’s later history, the Covenant linking, executive authority, public review, denominator challenge and the 314,159-credit balance. None of these pages exists in `draft-final.md`, which ends at Mera’s Page 47 message.
- **Smallest repair direction:** Writer, remove Pages 45–64 entirely. Stop the script at the approved Chapter 3 ending: Mera says, “Two found. He’ll want the third from me directly.”
- **Role:** Writer

#### 5. The script’s dialogue and visual beats are not word-for-word from `draft-final.md`

- **Location:** Throughout `script.md`, especially Pages 11–44.
- **Problem:** The script changes approved lines and actions. Examples include Bi11bot’s introduction changing from “You’re taller than your father predicted” to “Adrian’s jaw. His poorer timing”; the workshop sequence being reorganized; the Measure sequence gaining different captions and panel divisions; and the Maker’s Seal sequence being replaced by later material. The showrunner’s instruction explicitly classifies dropped, merged, reordered or altered draft beats as Blockers.
- **Smallest repair direction:** Writer, use `draft-final.md` as the sole source. Put every approved line into balloons word for word, preserve every approved beat and mark each page `CHANGED: none` unless a drawability adjustment is genuinely unavoidable.
- **Role:** Writer

### Major

#### 6. The current script cannot be repaired by layout-only changes

- **Location:** `layouts.md`, `thumbnails.md`, and `script.md` as a combined production set.
- **Problem:** The existing layouts and thumbnails reinforce the 64-page alternate book, including TJ’s 2099 lake plot and Pages 45–64. They are therefore built around the wrong script and cannot be treated as a valid execution pass.
- **Smallest repair direction:** Writer, deliver the corrected 47-page script first. Layout Agent, regenerate layouts and thumbnails only after that script is approved; do not patch the existing 64-page layouts.
- **Roles:** Writer, Layout Agent

#### 7. Prohibited House names remain in the execution artifacts

- **Location:** `layouts.md`, Pages 39–40; `thumbnails.md`, Pages 39–40.
- **Problem:** These artifacts use “Caldera House,” “Vector” and “Orbital,” while canon fixes House Calder, House Ivers and House Steyn. Although the corrected 47-page script must be rebuilt before layout, these existing artifacts remain unsafe production references.
- **Smallest repair direction:** Layout Agent, after receiving the corrected script, regenerate all House signage and labels using only House Calder, House Ivers and House Steyn. Letterer, audit visible lettering after regeneration.
- **Roles:** Layout Agent, Letterer

#### 8. The script/layout package contains a prohibited 2099 object on Page 64

- **Location:** `script.md`, Page 64; `layouts.md`, Page 64; `thumbnails.md`, Page 64.
- **Problem:** The script describes the foreground as a damaged drone component from 2099, while the execution correction says it must be a 2043 verified Measure record. This is another symptom of the wrong 64-page version and would create a direct visual contradiction.
- **Smallest repair direction:** Because Page 64 is not part of the approved 47-page book, Writer must remove it with the rest of the alternate material. If the page is retained in any future approved version, the object must be the 2043 Measure record.
- **Roles:** Writer, Layout Agent

#### 9. Existing layouts violate the showrunner’s current drawability contract

- **Location:** `layouts.md`, Pages 1–10 and later pages; `thumbnails.md`, Pages 1–64.
- **Problem:** The current package includes a 10-page prologue with multiple moving pieces and named characters, crowd-dependent scenes and later pages carrying more characters and institutional material than the current approved 47-page script will support. It is not possible to validate these layouts against the approved book because they belong to a different pagination.
- **Smallest repair direction:** Layout Agent, regenerate one location per page where possible, no more than four panels, no more than three named characters per panel and no recognizable crowd that must carry story information. Recheck every page after the Writer’s 47-page script arrives.
- **Role:** Layout Agent

### Minor

#### 10. Page checks do not match the required source order

- **Location:** `script.md`, existing `PAGE CHECK` entries.
- **Problem:** The current checks describe the alternate 64-page book rather than the approved `draft-final.md`. They therefore cannot serve as continuity sign-off.
- **Smallest repair direction:** Writer, replace each page check during the 47-page rebuild and end every page with `CHANGED: none`, unless an explicit drawability change is documented.
- **Role:** Writer

#### 11. The current execution notes preserve obsolete production decisions

- **Location:** `layouts.md`, Production decisions.
- **Problem:** Statements such as “TJ appears only on Pages 1–10” and the 64-page page-index check contradict the showrunner’s current 47-page instruction and the approved prologue.
- **Smallest repair direction:** Layout Agent, delete obsolete production decisions when regenerating the package from the corrected script. Do not carry forward the old page-index check.
- **Role:** Layout Agent
