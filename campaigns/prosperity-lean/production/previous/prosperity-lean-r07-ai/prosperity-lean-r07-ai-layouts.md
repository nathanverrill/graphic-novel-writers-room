# layouts.md

## Base page system

**Format:** 6.625" × 10.25", full color, Western left-to-right reading.  
**Base grid:** Four-panel variable tiers, with one full-page splash on Page 10.  
**Drawability rules:** No more than four panels per page; no more than three named characters in a panel; crowds remain non-recognizable; each page stays within one primary location where possible.  
**Lettering:** Artwork contains no rendered text. Every display, balloon, caption, and SFX is supplied below with a reserved clear zone.  
**Continuity:** The single white-and-amber node remains the same node throughout Pages 5–12. Alex always wears Adrian’s oversized steel watch on his left wrist. Bi11bot remains non-menacing, with soft amber eyes only.
