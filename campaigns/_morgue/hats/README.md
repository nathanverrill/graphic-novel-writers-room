# Hats (retired)

De Bono's six thinking modes (blue process, white evidence, black risk, yellow value, red
reaction, green possibility). One could be picked for a run and was added to every agent's
system prompt.

Retired on 2026-09-20 with the move to four phases. A hat was a second, optional axis on every
run — which agents, *and* in which mode — and the phases already say what kind of thinking each
step is for: the First Reader is the red hat, the Continuity Editor the black, the audition the
green. To bring one back, paste its text into a showrunner note.
