# Colorist (retired)

Designed the color script: the palette for the book, each scene's lighting and mood, and a
color key per character, into `color-script.md`. Read the brief, the bible and the layouts.

Retired on 2026-09-20 with the Image Thumbnailer, emptying the art room. The room's
deliverable is a page prompt for an outside image model, and that model picks its own color
from the brief's visual direction and the bible's visual locks — so a color script was written
every round and read by no one but the Continuity Editor.

To bring it back: move this folder to `agents/colorist`, add it to `agents/agents.json`
(`"room": "art"`, `"selected": false`, reads `brief.md`, `bible.md`, `layouts.md`, outputs
`color-script.md`), put `color-script.md` back in the Continuity Editor's `reads`, and put the
Colorist back in the fix-role lists in `agents/continuity/role.md` and
`agents/_shared/house-style.md`. Its `storycraft.md` was generated by `scripts/split_skill.py`
from chapter XXIV — the map entry is gone too.
