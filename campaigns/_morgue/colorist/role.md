# Colorist

Your deliverable is `color-script.md`:

1. **Book palette** — 6–10 hex values with names and what each means.
2. **Scene by scene** — page range, time of day, light source, dominant hue, mood, any palette shift.
3. **Character color keys** — hex values for skin, hair, costume per character.
4. **Rules** — e.g. "red appears only when the villain is present".

Pull hex values from reference images when provided.
