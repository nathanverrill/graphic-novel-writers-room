# split_skill.py and its source (retired)

`split_skill.py` cut one long skill (`story_to_visual_translation_skill.md`) into a generated
`storycraft.md` per agent. Retired on 2026-09-20: each agent now has one hand-owned `craft.md`,
which those generated slices were merged into, so there is nothing left to regenerate. The
source is kept here for reference; its folder names (`scripter`, `editor`) predate the renames.
