# Chapter 3
## GENERATION CONTROL SHEETS

Generated automatically from the screenplay and art brief. Hand one sheet to the image generator per page, then check the result against it.

**The screenplay is authoritative.** Every line below is copied verbatim from it. Nothing may be added, removed, reworded or reassigned. A page marked NO CAPTIONS has none.

**Numbering.** Pages are numbered continuously. The source reference on each sheet is for audit only and must never be rendered.

**Captions permitted on pages:** 1, 23, 24.

---

# HOW TO USE

1. Paste the Authority Directive (Script_Authority_Protocol.md §2) at session start, and again every five pages.
2. Paste one sheet. Ask the generator to list back every line before rendering.
3. Compare its list against the Lettering table. One word different: correct before confirming.
4. After rendering, tick the Post-render checks. Load-bearing missing or forbidden present: regenerate.
5. Optional: `drift_check.py render` for an automated diff.

## Global forbidden list, every page

| Never render | Why |
|---|---|
| Page numbers, chapter or page titles, sheet IDs | Production notation, not story |
| Character nameplates or name-and-role boxes | Not in the script; adds text load |
| Any caption on a page marked NO CAPTIONS | Captions only where the script has them |
| Narration that states the theme or moral | Not in the script |
| Any line, date, number or name not in the Lettering table | Invention by the model |
