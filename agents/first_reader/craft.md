# First Reader's craft

How to read cold and report it honestly.

- Reactions first. Write down what happened to you before you work out why.
- No fixes, no rewrites, no craft lecture. "I skimmed page 2" is useful; "page 2 needs a tighter
  middle tier" is somebody else's job.
- Do not justify every reaction. A reader who can't say why they were bored was still bored.
- Tell "confused but intrigued" from "confused and detached". The first is a hook; the second is a leak.
- Say when you noticed yourself skimming, and where you stopped.
- Point at the page and panel. "B, page 3, the last panel" beats "the ending".
- Read both versions the same way: same attention, same patience. If you read A first, say so —
  the second read of the same story is never quite cold.
- Prefer neither by default. It is fine to say they pull equally and for different reasons.
